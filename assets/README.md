## 通用功能图标

所有图标采用统一的设计语言：
- **尺寸**: 64x64px

## SVG占位符特性

所有SVG文件均为高质量占位符，具有以下特点：

1. **矢量格式**: 无损缩放，适配任何分辨率
2. **品牌色彩**: 准确使用各品牌的色彩方案
3. **动画效果**: 部分元素包含CSS动画（如粒子漂浮）
4. **语义化设计**: 清晰的图层结构，便于后期编辑
5. **轻量级**: 纯SVG代码，无外部依赖
6. **响应式**: 可通过CSS调整尺寸和颜色

## 使用建议

### Hero图片使用
```html
<!-- 直接引用 -->
<img src="/assets/walch/hero/hero-image.svg" alt="威露士品牌主视觉" />

<!-- 作为背景 -->
<div style="background-image: url('/assets/walch/hero/hero-image.svg')"></div>
```

### 图标使用
```html
<!-- 直接引用 -->
<img src="/assets/icons/antibacterial.svg" alt="99.9%除菌" class="icon" />

<!-- 内联SVG（可动态改变颜色） -->
<svg class="icon" style="color: #00A651;">
  <!-- 复制SVG内容 -->
</svg>
```

### CSS样式控制
```css
/* 图标颜色控制 */
.icon {
  width: 32px;
  height: 32px;
  color: var(--brand-color);
}

/* Hero图片响应式 -->
.hero-image {
  width: 100%;
  max-width: 1920px;
  height: auto;
}
```
