# 威莱洗护矩阵品牌展示网站
# Welly Care Matrix - Brand Showcase Website

## 项目概述

威莱洗护矩阵是一个高端品牌展示网站，展示威莱集团旗下5个专业洗护品牌，覆盖从大众到高端的完整衣物洗护市场。

## 品牌矩阵

### 1. 威露士 (Walch) - 大众杀菌基石
- **定位**: 大众市场领导者 - 专业杀菌消毒洗护品牌
- **价格区间**: ¥15-45/件
- **目标用户**: 注重健康卫生的广大家庭用户
- **核心卖点**: 99.9%除菌率、全场景覆盖、性价比高
- **品牌色彩**: #00A651 (绿色) / #0066CC (蓝色) / #FFB81C (黄色)

### 2. Na (奈十八本) - 高端香氛艺术
- **定位**: 高端香氛洗护 - 融合国际香氛艺术与洗护科技
- **价格区间**: ¥89-299/件
- **目标用户**: 25-40岁都市新中产，追求生活品质
- **核心卖点**: 国际调香师配方、72小时持香、18种香型
- **品牌色彩**: #2C2C2C (黑色) / #D4AF37 (金色) / #E8D5C4 (奶茶色)

### 3. Lamama - 母婴专业守护
- **定位**: 母婴专业洗护 - 专注0-6岁婴幼儿及孕产妇
- **价格区间**: ¥38-88/件
- **目标用户**: 新生儿及学龄前儿童的母亲，注重产品安全性
- **核心卖点**: 0添加配方、低敏认证、A类婴幼儿标准
- **品牌色彩**: #FFB6C1 (粉色) / #87CEEB (天蓝) / #FFF8DC (奶白)

### 4. 菁华 (Jinghua) - 天然植物洗护
- **定位**: 天然植物洗护 - 主打天然植萃和环保理念
- **价格区间**: ¥28-68/件
- **目标用户**: 28-45岁注重健康环保的中产家庭
- **核心卖点**: 90%植物成分、生物可降解、FSC认证包装
- **品牌色彩**: #6B8E23 (草本绿) / #8FBC8F (海绿) / #F0E68C (米黄)

### 5. 纺优美 (Fangyoumei) - 专业面料护理
- **定位**: 专业衣物护理 - 针对高端面料和特殊材质
- **价格区间**: ¥45-128/件
- **目标用户**: 30-50岁拥有高端衣物的品质消费者
- **核心卖点**: 专业面料护理技术、纤维修复、防皱抗静电
- **品牌色彩**: #4A5568 (灰色) / #B8860B (古铜金) / #E6E6FA (淡紫)

## 设计理念

### 矩阵定位架构（金字塔模型）
```
高端层：    Na (香氛艺术)  |  纺优美 (专业护理)
中高端层：  Lamama (母婴)  |  菁华 (天然植萃)
大众基石层：威露士 (杀菌健康)
```

### 视觉设计特点
- **金字塔矩阵视觉模型**: 单页应用设计，全屏品牌矩阵可视化
- **三层导航系统**: 顶部固定导航栏、侧边圆点导航、品牌内部锚点
- **品牌动态色彩**: 切换品牌时页面主题色渐变过渡
- **现代交互效果**: 3D卡片悬停、视差滚动、平滑动画

## 技术栈

### 前端技术
- **HTML5**: 语义化结构、可访问性优化、SEO优化
- **CSS3**: 现代CSS（Grid、Flexbox、CSS变量）、响应式设计
- **JavaScript (ES6+)**: 原生JavaScript、模块化架构、性能优化

### 核心功能
1. **页面加载动画**: 品牌色彩流动效果
2. **智能导航**: 滚动阴影、平滑滚动、活跃链接高亮
3. **视差滚动**: 背景和内容差速运动，营造深度感
4. **品牌卡片动画**: 3D倾斜悬停、交错入场动画
5. **图片懒加载**: IntersectionObserver优化性能
6. **滚动显示**: 元素进入视口时触发动画
7. **响应式设计**: 桌面优先，完美适配各种屏幕

## 本地运行

### 方法1: 直接打开
直接在浏览器中打开 `index.html` 文件即可查看。

### 方法2: 使用本地服务器（推荐）
```bash
# 使用Python
python -m http.server 8000

# 使用Node.js
npx http-server

# 使用PHP
php -S localhost:8000
```

然后在浏览器访问 `http://localhost:8000`
